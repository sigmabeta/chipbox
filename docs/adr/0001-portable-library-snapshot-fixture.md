# Portable library snapshot as the benchmark fixture

Device benchmarks need a deterministic library without paying for a scan on
every run. The obvious fixture is a copy of the Room `library.sqlite`, but
`Track.path` stores a **machine-absolute** path and the DB is version-coupled
(`ChipboxDatabase` v12, `fallbackToDestructiveMigration`, no exported schema),
so a raw DB file is neither portable between machines nor stable across app
versions. We store a **library snapshot** instead: a serialized list of games
and tracks, generated by running the real host scanner once (`perfbench
snapshot`) with paths stored relative to the corpus root and rebased at import.
It survives Room version bumps and machine changes, at the cost of an import
step and a snapshot format to maintain.
